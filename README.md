SuperSuit — Rental Management System (PHP + MySQL)

Полноценное веб-приложение для аренды костюмов.
Включает каталог, карточки товаров, админ-панель, загрузку изображений, галерею и систему управления наличием.

🚀 Features

PHP 8 + PDO (prepared statements)

ООП Database wrapper

Admin panel with CRUD operations

Multiple image upload with sorting

Swiper.js gallery

Product availability & filtering

SKU auto-generation

Transaction-safe product insertion

Fully responsive UI

Secure file upload

XSS & SQL Injection protection

🧩 Tech stack
PHP, MySQL, PDO, JavaScript, Swiper.js, HTML, CSS
(в процессе интеграции: Laravel)
